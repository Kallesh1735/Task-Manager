 # 🧭 Task Manager

A modern **React Task Manager** app built with **Framer Motion** and **Glassmorphism UI**.  
It helps you create, track, and organize your tasks efficiently — with smooth animations, theme switching, and a live progress bar.

---

## ✨ Features

- 🪶 **Beautiful Glass UI** — clean, minimal, and responsive  
- ⚡ **Add, Edit, Complete, or Delete tasks** easily  
- 🎯 **Progress Tracker** — auto-updates when tasks are completed  
- 🌗 **Dark / Light Theme Toggle** with local storage persistence  
- 🔍 **Search, Filter, and Sort** by status, category, and due date  
- 📊 **Stats Dashboard** — total, active, completed, and overdue task counts  
- 💾 **Local Storage** — all your data stays safe locally  
- 🎬 **Smooth Animations** powered by Framer Motion  

---

## 🛠️ Tech Stack

- **React (Vite)**  
- **Framer Motion** for UI animations  
- **Local Storage API** for persistence  
- **CSS Glassmorphism + Blur effects**
